# HDBSCAN Clustering and Geocoding of Ridership to Determine Optimal Stops Location

This project clusters GPS boarding and alighting points using HDBSCAN, snaps the clusters to the nearest common (but not official) stops or points of interests, reverse geocodes their addresses, and outputs the results in CSV, shapefile, and image formats. It is designed for public transport boarding and alighting data analysis and GTFS generation, with examples from Iloilo City public transport routes.
